# BBJ2 Load & Balance — EFB Royal Air Maroc

Application EFB (*Electronic Flight Bag*) Progressive Web App (PWA) pour le calcul de masse et centrage, limitations de performance OPT, devis de masse et Flight Log opérationnel pour Boeing BBJ2 (CN-MVI).

## 🚀 Fonctionnalités
* **Calcul Masse & Centrage** : DOW, DOI, ZFW, TOW, LAW, avec tracé dynamique de l'enveloppe MAC en temps réel.
* **Mode Cockpit Jour / Nuit** : Bascule globale et persistante sur toutes les pages.
* **Assistant EFB W&B** :
  * Silhouette interactive du fuselage avec disposition VIP (Lounge, Office, Bedroom, Stateroom).
  * Réservoirs de carburant animés (Wing Tanks 3 950 kg, Center Tank 12 700 kg, Auxiliary Tanks).
  * Détection et mise en surbrillance automatique de la limitation la plus contraignante (*Computed Limitations*).
* **Flight Log Complet** :
  * Enregistrement des secteurs et navigants.
  * Calcul automatique du temps de vol de nuit aéronautique (crépuscule civil selon coordonnées ICAO).
  * Détection des vols incomplets (< 2 Crew ou On-Block manquant).
  * Popup d'ajout rapide de navigant dans la base Crew directement depuis la ligne du Flight Log.
* **100% Hors-Ligne (PWA / Mode Avion)** :
  * Fonctionne sans serveur ni internet une fois installé sur l'appareil.
  * Données persistées localement.

## 🍏 Installation sur iPad / iPhone (Safari)
1. Ouvrez l'URL GitHub Pages dans **Safari**.
2. Appuyez sur le bouton **Partager** (carré avec flèche vers le haut).
3. Sélectionnez **« Sur l'écran d'accueil »** (*Add to Home Screen*) puis **Ajouter**.
4. L'icône BBJ apparaît sur votre écran d'accueil et s'ouvre en plein écran sans barre d'adresse.

## 🤖 Installation sur Android (Chrome)
1. Ouvrez l'URL dans **Google Chrome**.
2. Cliquez sur le menu `⋮` en haut à droite > **« Installer l'application »** (ou suivez le bandeau en bas).
